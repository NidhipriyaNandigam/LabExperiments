Purpose

This repository contains C programs completed for the PPS lab experiments. The programs are arranged week by week so they are easy to find and review.

Folder Structure

Create a separate folder for each week and place that week's experiment programs inside it, for example:

Lab Experiments/
├── Week 1/
├── Week 2/
├── Week 3/
├── Week 4/
└── Week 5/

List of Experiments

Week 1

Experiment 1: Write simple C programs using printf() and scanf().

Week 2

Experiment 1: Find the sum and average of three given numbers.

Experiment 2: Convert Fahrenheit to Celsius and Celsius to Fahrenheit.

Experiment 3: Calculate simple interest using principal amount, rate of interest, and time period.

Week 3

Experiment 1: Find the square root of a given number.

Experiment 2: Calculate compound interest using principal amount, rate of interest, and time period.

Experiment 3: Calculate the area of a triangle using Heron's formula.

Experiment 4: Calculate the distance travelled by an object.

Week 4

Experiment 1: Evaluate the given expressions in C.

Experiment 2: Find the maximum of three numbers using the conditional operator.

Experiment 3: Read marks for five subjects and calculate the total and average.

Week 5

Experiment 1: Find the maximum and minimum of four numbers using if-else.

Experiment 2: Calculate a household electricity bill based on the given unit slabs.

Experiment 3: Find the roots of a quadratic equation.

Experiment 4: Create a menu-driven calculator using switch.

Experiment 5: Check whether a given year is a leap year.

Language and Concepts

Programming language: C

Concepts used: input/output, variables, arithmetic operators, conditional statements, the conditional operator, and switch statements.

How to Run

Open the required .c file in a C compiler or IDE.

Compile the program.

Run the program and enter the requested input.

Check that the output is correct before uploading the file.
